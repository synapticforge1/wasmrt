# tests/

wasmrt's repo-level test assets: the C-ABI gate sources, the behaviour carry-forward corpus, and
`.wast` scripts for cases the official spec testsuite cannot express. Every gate, what it can and
cannot see, and its dated counts: [`../cmem/testing.md`](../cmem/testing.md).

## C-ABI gates — each catches what the others cannot

Run both with **`bun ../scripts/c-gate.ts`** (add `--release` for the release lib; `CC=gcc` where
there is no `cc`).

- **`abi_symbols.c` — 75 symbols resolved** (2026-10-24). Takes the address of every function
  `wasmrt.h` declares, forcing the linker to resolve it. A function DECLARED in the header but never
  EXPORTED fails the **build** — the one failure mode nothing else catches, because compiling a
  declaration always succeeds. **Keep it in step with the header: a new declaration means a new line
  here.** (The header's own list is also in `../surface/current.txt`.)
- **`c_smoke.c` — PASSED** (2026-10-24). Compiled by a C compiler against the *shipped* header, so it
  proves two things no Rust test can: that `wasmrt.h` is valid C, and that its declarations match the
  exported symbols. Drives config → compile → link a host import → instantiate → call → memory both
  ways → global → trap → teardown, and checks that a foreign-store handle is refused. Its module bytes
  are embedded, so the gate fails for exactly one reason: the ABI.
- **Miri — 32/32 on 2026-09-19** via **`bun ../scripts/miri-gate.ts`**, including `lifecycle_fuzz`
  (`crates/wasmrt-capi/src/tests.rs`), which drives randomized creation, use and destruction orders and
  touches handles whose store is already gone. Re-count it on every run.

**These gates can fail.** Mutation-verified: deleting the store-tag check from handle unpacking makes
the cross-store test fail.

## The rest

- **`behaviour/`** — the S1 carry-forward corpus (71 modules, generated by
  `bun ../scripts/behaviour-corpus.ts`), judged in every `cargo test` against
  `behaviour-snapshot.txt`; `spec-snapshot.txt` is S2's per-file record (`../cmem/releasing.md`,
  step 1c).
- **`*.wast`** — scripts for cases the spec suite cannot spell (value-type encodings, exact-type
  confusion, descriptor casts, externref bridging, …), run by `wasmrt wast` like the suite itself.
- **Correctness anchors:** the official spec testsuite, wasmtime's observable behaviour, and the wasmtk
  WASI corpus. The wazmrt-parity gates of the port were retired with the oracle on 2026-08-11.
